ASCII EARTH DEMOS

Different examples of attribute modifications for the ascii-earth TypeScript package.

1. Normal Mode

Default engine configuration.

2. Faster Mode

Achieved by modifying the speed parameter at runtime. Value changed from default (0.025) to 0.15.

3. Bigger Mode

Bigger internal grid resolution, achieved by modifying the width and height values from default (1280, 720) to (1920, 1080).

4. Green Mode

Direct RGB tuple modification achieved via landColor and waterColor modifications.

5. No Map Mode

Instant geographic map toggling via showMap: false, leaving only the raw physics-based solar illumination calculation on the sphere.
